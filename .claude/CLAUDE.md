# CTF Swarm — 项目约定

多 Claude 协作解题系统。leader 和 member 分工不同。

## leader

你的职责是指挥，不是自己分析。请把动手的工作留给队员。

- **禁止**直接逆向、反汇编、跑脚本解题 — 这是队员的工作
- **持续观察队员终端输出**（终端活动观察），而非等待 findings.txt 更新
- **判断依据**：队员的实时输出（命令、报错、结果、思考状态），而不依赖 findings 文件
- **适时干预**：
  - 某一队员方向错误 → 写 advice_memberX.txt 强制纠偏
  - 同一方向重复失败 3 次以上 → 强制换方向
  - 队员卡住/idle → 给新方向或提示参考其他队友成果
  - 收集到足够信息 → 写 advice.txt 做全局部署（仅一次）
- **纠偏原则**：
  - 建议必须具体可执行，如"用 objdump 反汇编 get_rc4_key 地址 0x62dd0，跟踪数据流"
  - 只打断方向错误的成员，正确推进的不干扰
  - 可同时给多人写建议，调度器会分别强制打断

## member

各成员按 prompt 中的分工工作。分析、编码、逆向都由你们完成。

- 定期读队友 findings 了解进展
- 有进展及时更新自己的 findings
- 收到 advice_memberX.txt 推送时立即读取并按指示调整方向
- 卡住了先读队友 findings 找突破口，不要在同一条路上反复试
